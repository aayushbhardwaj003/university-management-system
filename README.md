# University Management System

A Python + MySQL based University Management System project.

## Features
- Add student records
- Delete student records
- Update student information
- Show instructor details
- Show enrolled students in courses
- Deposit HRA and deduct TDS

## Technologies Used
- Python
- MySQL
- mysql-connector-python

## How to Run

1. Run the SQL file in MySQL Workbench:
   - Idb_project.sql

2. Install dependency:
   pip install mysql-connector-python

3. Run the Python program:
   python university_management.py
